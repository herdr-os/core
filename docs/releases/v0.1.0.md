First public release of Herdr OS: a Rabbit R1 that keeps you company while your coding agents work.

Install from Chrome at <https://herdr-os.org/install>, or by hand with [docs/INSTALL.md](https://github.com/herdr-os/core/blob/main/docs/INSTALL.md).

## What's in it

- **The R1 app** (`herdr-os.apk`): your agents as sheep on a pasture, questions you answer with a
  touch, walkie-talkie replies on the side button, photos, threads, subagents, running commands,
  a read-only terminal and a model picker.
- **The Magisk module** (`herdr-os-module.zip`): wheel and button mapping, power defaults, no
  Android lock screen, and the Herdr boot animation.
- **The bridge** (`herdr-bridge.tar.gz`, also `npm i -g @herdr-os/bridge`): runs next to Herdr on
  your computers and speaks for Claude Code, Codex, Pi, OpenCode and every other harness Herdr runs.
- **Magisk 30.7**, unchanged from [topjohnwu/Magisk](https://github.com/topjohnwu/Magisk) (GPLv3).

## Good to know

- This is a preview: the app is signed with a development key, not a stable release key.
  Updates from this key install over it; a future stable key will need a reinstall.
- Installing erases the R1 and voids Rabbit's warranty. The installer says so before every step
  that does.
- Check downloads against `SHA256SUMS`.
